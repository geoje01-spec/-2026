# 숨비 지킴이 · 해녀바당

해녀의 안전(숨비 지킴이)과 소득(해녀바당)을 돕는 웹앱. 데모데이 시연용이며 응급 신고는 모의 신고입니다.

**전체 정리(기능·시연 순서·설정·남은 일): [프로젝트_정리.md](프로젝트_정리.md)**

## 숨비 지킴이 (`/`)
마이크로비트로 해녀의 물질 상태(물속·물 위)를 관제하고, 위급하면 확인 절차 후 모의 신고. 실측 수온·기상청 해상예보로 오늘 물질 판단. 스스로 살피고 행동하는 AI 에이전트.
- 마이크로비트: 기본 방식(`haenyeo_sender_python.py`, `receiver_python.py`) 또는 부표 방식(`buoy_receiver_python.py`)

## 해녀바당 (`/market/`)
해녀가 사진 한 장으로 해산물·체험을 알리고, 손님이 **익명 채팅**으로 주문해 **무인 냉장고**에서 비밀번호로 받아 가는 게시판. 이름·전화번호는 저장하지 않고 서로 별명으로만 보임. 주문·결제·배송 기능 없음, 수수료 없음.
- 로그인·회원가입(해녀/손님), 지도·길찾기, 후기와 AI 욕설·비방 검사, aT 시세 기반 추천 가격

## 키
API 키는 이 저장소에 넣지 않습니다. Vercel 환경변수로 넣습니다.
- `DATA_GO_KEY` 공공데이터포털 일반 인증키(Encoding)
- `GEMINI_KEY` Google AI Studio Gemini 키
- (선택) Upstash Redis: Vercel → Storage에서 연결하면 해녀바당 글·채팅·후기가 모든 기기에 공유됨. 연결 전에는 각 기기에만 저장

## 구성
- `index.html` 숨비 지킴이, `market/` 해녀바당
- `api/` 키를 숨긴 채 공공데이터·Gemini를 불러주는 서버 함수 (Vercel)
- `server.py` 인터넷 배포 없이 내 PC에서 실행할 때
